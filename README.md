# CubeCraft Skyblock Guide

A community knowledge base for CubeCraft Skyblock — covering money farming, XP progression, enchants, quest help, and game mechanics.

## Pages

- **Home** (`index.html`) — Overview and quick tips
- **Money Farming** (`pages/money.html`) — Best farms ranked, progression path
- **XP Farming** (`pages/xp.html`) — Dropper builds, Bedrock & Java guides
- **Enchants** (`pages/enchants.html`) — Optimal tool, weapon, and armor enchants
- **Quest Help** (`pages/quests.html`) — Common issues and fixes
- **Mechanics** (`pages/mechanics.html`) — Spawners, Fortune, Looting, Protection

## Publishing to GitHub Pages

1. Create a new repository on GitHub (e.g. `cubecraft-skyblock-guide`)
2. Upload all files maintaining the folder structure:
   ```
   index.html
   README.md
   css/style.css
   js/main.js
   pages/money.html
   pages/xp.html
   pages/enchants.html
   pages/quests.html
   pages/mechanics.html
   ```
3. Go to **Settings → Pages**
4. Set Source to **Deploy from a branch → main → / (root)**
5. Save — your site will be live at `https://yourusername.github.io/cubecraft-skyblock-guide/`
