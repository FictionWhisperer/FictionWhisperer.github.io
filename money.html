Fastest Progression Path

Follow this order for the fastest route to top-tier money farming:

  1. Cocoa Beans — Only needed for the "Blot Out the Sun" quest. Get it done early and move on.
    Cocoa Bean Farm Video
  2. Melon Farm — Build a large melon farm on Birch Island.
    • Use Fortune + Silk Touch on an Axe for max efficiency, or
    • Build a very large farm and use Efficiency + Silk Touch to mine faster.
  3. Unlock the Nether — Do this in parallel with melon farming. Talk to the Gatekeeper NPC to begin.
  4. Pig Spawners (Savannah) — By the time you reach Savannah, you should have a few million from melons. Spend it on pig spawners and build the pig farm shown in the tutorial video.
  5. Upgrade to Creeper Farm — When ready, upgrade your existing pig farm. It's nearly the same build — just make these changes to your pig farm:
    • Remove the lava.
    • Swap the chessboard pattern (fence/glass pane) with cobblestone walls + lanterns.
💡 Pro Tip — Let it Rest Creeper farms take time to set up. You can build the full pig farm first and let it run passively while you work on other goals.

Avoid These Farms

These are inefficient or outdated — not worth your time:

  • Chicken Farm
  • Wood
  • Cactus Farm
  • Any crops before Desert
  • FractalCake's Pig Farm (outdated, expensive, slow)
  • Sugar
